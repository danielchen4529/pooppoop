## 1. 專案概述

### 背景與動機

腸道健康是整體健康的重要指標，但大多數人對自己的排便狀況缺乏系統化的記錄與認識。市面上缺乏一個簡單易用、又能提供有意義分析的糞便記錄工具。本專案旨在打造一個輕量、友善的 Web 應用，讓使用者能輕鬆記錄每日排便狀況，並透過布里斯托大便分析法（Bristol Stool Scale）獲得 AI 驅動的健康洞察與飲食建議。

### 目標用戶

| 用戶族群 | 使用情境 |
|---|---|
| 大學生與上班族 | 生活步調快，飲食不規律，希望快速記錄並了解自身腸道狀況 |
| 年長者 | 腸道健康需要長期追蹤，需要簡單直覺的操作介面 |

### 核心價值主張

- **輕鬆記錄**：30 秒內完成一筆排便日誌
- **智慧分析**：運用布里斯托大便分析法與 AI，給出具體健康建議
- **長期追蹤**：歷史記錄視覺化，發現健康趨勢
- **情緒連結**：結合心情記錄，幫助用戶了解壓力與腸道健康的關係

## 2. 功能需求

### 功能 1：排便日誌記錄

**描述：** 使用者可以快速新增一筆排便記錄，包含時間、形狀類型、顏色、備註等欄位。

**使用者故事：**
> 作為一名 **使用者**，我希望 **能快速填寫今日的排便記錄（包含時間、形狀、顏色）**，以便 **建立長期的腸道健康檔案**。

**接受條件：**
- 表單包含：日期時間、布里斯托類型（Type 1–7）、顏色選擇、氣味描述（可選）、備註（可選）
- 提交後顯示成功提示訊息
- 資料儲存至資料庫

---

### 功能 2：AI 分析糞便狀況（布里斯托大便分析法）

**描述：** 系統根據使用者填寫的布里斯托類型，透過 AI 提供健康狀態分析與解讀。

**使用者故事：**
> 作為一名 **使用者**，我希望 **提交記錄後能看到 AI 對我的糞便類型的分析說明**，以便 **了解自己的腸道健康狀態是否正常**。

**接受條件：**
- 根據布里斯托 Type 1–7 提供對應的健康說明
- AI 結合顏色、頻率等資訊給出綜合評估
- 分析結果以易讀的視覺化卡片呈現

## 3. 非功能需求

### 技術限制

| 類別 | 技術選擇 |
|---|---|
| 後端框架 | Flask (Python) |
| 模板引擎 | Jinja2 |
| 資料庫 | SQLite |
| 前端 | HTML / CSS / JavaScript（Vanilla） |
| AI 分析 | OpenAI API 或本地規則引擎（MVP 階段使用規則引擎） |

### 效能考量

- 頁面載入時間 < 2 秒
- 表單提交回應時間 < 1 秒
- SQLite 資料庫需支援至少 10,000 筆記錄無明顯效能降級

### 安全考量

- 使用者資料（排便記錄）屬於隱私資料，需有基本的存取控制
- 防止 SQL Injection（使用 ORM 或參數化查詢）
- 防止 XSS 攻擊（Jinja2 預設 auto-escape）

### 可用性考量

- 介面需適合年長者使用：字體不小於 16px、操作步驟不超過 3 步
- 支援手機瀏覽器（RWD 響應式設計）
